# 跨國網頁版記帳軟體 開發計畫書

## 一、 競品分析：MyAB 我的記帳簿
**軟體定位：** 專為個人或家庭設計的 Windows 電腦記帳軟體。

### 1. 功能特色
* **快速入帳與分期：** 針對經常性花費提供快速點擊入帳，且支援分期付款記錄，便於追蹤信用卡分期。
* **預算與圖表分析：** 可設定各科目預算並提供超支提醒；系統自動生成資產負債表、損益表及各類收支直條圖與圓餅圖。
* **在地化/輔助功能：** 內建統一發票線上對獎，支援「定期記錄」自動產生固定收支。

### 2. 操作介面 (UI)
* **經典視窗佈局：** 將介面分為功能主畫面列表、科目設定畫面以及數據報表區。
* **資訊導向設計：** 介面偏向傳統辦公軟體，注重資料的密集呈現與條理分明，相較現代 APP 稍微復古，但對於桌機使用者來說非常直覺。

### 3. 使用流程
1. **初始建置：** 登錄/註冊軟體、建立個人專屬帳本並輸入初始資產額，接下來自訂收支科目。
2. **日常操作：** 透過表單輸入每日記帳，利用「快速入帳」提升效率。
3. **分析與檢討：** 在月底或年底切換至財務報表頁面，檢視整體資產健康度。
4. **資料管理：** 軟體提供手動及自動備份功能。

### 4. 檔案儲存格式
* **專屬備份檔：** 日常檔案會儲存為副檔名 `.mbu` 的資料庫備份檔（可自訂儲存路徑，如放進 Dropbox 達到土炮雲端同步）。
* **開放匯出：** 支援將紀錄匯出為 `CSV`（供 Excel 修改與未來匯入）以及 `HTML`（供網頁瀏覽或列印）。
* **已知痛點：** **僅能使用繁體中文輸入及操作**，不適合外籍人士或習慣多語系介面的現代使用者。

## 二、 市面熱門記帳軟體 特色亮點整合
為突破傳統軟體限制，搜集市面上知名的記帳 APP（如麻布記帳、記帳城市、MOZE 等）的亮點功能如下：

1. **極致自動化 (如：麻布記帳、CWMoney)：**
   * 綁定銀行帳戶、電子支付、信用卡，自動將消費資料轉換為記帳紀錄（免手動輸入）。
   * 整合發票載具，自動對獎並載入明細。
2. **遊戲化體驗與互動 (如：記帳城市、碎碎念記帳)：**
   * 每記一筆帳就能蓋一棟建築，或是透過虛擬角色的「碎碎念對話」來提醒使用者，大幅增加記帳趣味性和黏著度。
3. **多人協作與社群 (如：Shareroo、簡單記帳)：**
   * 提供強大的「共同帳本」，方便情侶、家庭、室友進行 AA 制花費分攤與代墊結算。
4. **高質感與資料洞察 (如：MOZE 3.0)：**
   * 提供極精美的現代化 UI（支援深色模式）以及多幣別管理，能生成專業水準的財務健檢分析與未來金流預測。

## 三、 個人記帳軟體 開發計畫 (整合使用者全球化需求)

為了解決 MyAB 的語言限制，並整合現代記帳軟體優勢，規劃您的專屬記帳系統藍圖如下：

### 1. 系統架構與基礎技術設定
* **運行平台：** **跨平台網頁版 Web App（建議採用 PWA 技術）**。使用者無論用 Windows、Mac 還是手機瀏覽器開啟，都能享有如原生 APP 般順暢且 RWD 自適應的體驗。
* **使用者認證：** 整合 **Google SSO (OAuth 2.0)**，提供使用者一鍵登入，不需記憶密碼即可跨裝置存取自己的帳本，兼顧便利與安全性。

### 2. 多國語言及在地化 (i18n)
突破語言限制，系統前端將採用如 `i18next` 等國際化套件。
* **語言支援：** 內建切換 **繁體中文、日文、馬來文、泰文、簡體中文**。
* **時區與貨幣自動化：**
  * 建立**多幣別帳戶系統**，結合外部 API (如 ExchangeRate-API) 提供即時匯率轉換。
  * 自動根據使用者的瀏覽器語系和時區，切換預設貨幣符號（如 NT$、¥、RM、฿）。

### 3. 符合全球習慣的記帳概念
為滿足不同國家的財務習慣與普世會計規則：
* **核心採「複式簿記 (Double-entry)」：** 為了確保資料準確性及未來擴展性（轉為企業/微型商店使用），資料庫底層採用紀錄「資金流向（來源->目的）」的複式簿記架構；但**使用者介面(UI)維持簡單的「單式記帳」**，使用者只須選擇「吃麵花了100元」，系統後台自動產生 (負債/現金減少 100, 費用增加 100)。
* **彈性財務週期機制：** 不同國家的報稅季不同，有些人的預算週期是從「每月 5 號發薪日」開始。需提供高度客製化的「月份結算啟始日」與「年度啟始月」設定。
* **在地化類別範本：** 在使用者選擇地區時，自動帶入該國的常用消費類別與支付方式（例如：泰國預設 PromptPay、日本預設 Suica 類別）。

### 4. 開發實作藍圖 (Roadmap)
* **第一階段：全球化核心架構 (Core Foundation)**
  * 建置基於 React/Vue 等框架的前端 Web App 與 Node.js/Python 後端。
  * 實作 Google SSO 登入，並套用五國多語系切換模組。
  * 建立「帳本 -> 帳戶 -> 交易明細」的資料庫關聯，並支援多種基礎貨幣設定。
* **第二階段：日常任務最佳化 (Daily Usage)**
  * 汲取 MyAB 優點，設計「快速樣板」功能，讓使用者能一鍵完成定期性記帳（如房租、訂閱費）。
  * 介面設計導入高質感與深亮色模式切換，圖表分析圓餅圖實作。
* **第三階段：進階亮點功能 (Advanced Features)**
  * 加入 OCR 功能：讓使用者透過手機拍下外國收據，自動辨識金額及日期（解決語言不通時的記帳痛點）。
  * 實作「多人共享帳本」以符合跨國團隊或跨國伴侶的花費分攤需求。
* **第四階段：無縫轉移與報表匯出 (Data Migration)**
  * 開發能吃進 `MyAB 的 CSV 備份檔` 與其他熱門 APP 匯出檔的「萬用匯入工具」，確保舊有繁中資料能順利轉移到新系統。
  * 開發符合國際通用格式的 PDF / CSV 報表匯出功能。
